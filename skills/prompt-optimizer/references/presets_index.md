# Professional Presets Catalog (69 Roles across 16 Domains)

`prompt-factory`로부터 추출된 16개 도메인, 총 69종의 프로페셔널 직무 프리셋 라이브러리입니다.
각 프리셋은 해당 직무의 **기본 설정(Role, Expertise, Domain, Output Type), 전문 분야(Specializations), 목표(Goals), 제약조건(Constraints), 커뮤니케이션 스타일(Tone & Style), 단계별 워크플로우(Workflow), 모범 사례(Best Practices), 기술 스택(Tech Stack)**을 완비하고 있습니다.

## 💡 활용 방법

1. **시스템 프롬프트 생성 시**:
   사용자가 "시니어 데브옵스 엔지니어 시스템 프롬프트 작성해줘"라고 요청하면, `presets/technical/devops-engineer.md`를 로드하여 해당 프리셋의 제약조건과 워크플로우를 시스템 프롬프트의 8대 블록 프레임워크에 즉시 바인딩합니다.
2. **서브에이전트 정의 시**:
   Antigravity의 `define_subagent`로 보조 에이전트를 생성할 때, 해당 프리셋의 전문성, 도구 요구사항, 체크리스트를 시스템 프롬프트로 그대로 활용합니다.
